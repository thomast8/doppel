# Doppel 1.2.0

- Adds an experimental, per-profile Browser extensions control for the profile assigned Doppel's built-in Browser.
- Guides installation of Apple's official iCloud Passwords extension without exporting, copying or inspecting credentials.
- Preserves OpenAI's unknown feature settings and safely relinquishes the override when OpenAI enables extensions upstream.
- Keeps installed extensions and Browser data when the Doppel override is disabled.
