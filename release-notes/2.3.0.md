# Doppel 2.3.0

- Claude instances keep up with Claude. When the Claude app updates itself, Doppel notices the instances it left behind and offers to rebuild them from the menu bar panel, with a progress bar, the same way ChatGPT updates already work. Settings › Updates now shows Claude beside ChatGPT.
- Claude instances bring over your Code history by themselves. Sign in and open Code once, and the next launch copies the sessions for that same account and workspace from the original Claude app. Import… in the instance window still does it on demand.
- Tinted Claude icons now follow dark mode, with a dark tile and a tinted star. An existing Claude instance picks up the new icon the next time it is rebuilt.
