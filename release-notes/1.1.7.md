# Doppel 1.1.7

- Removing or rebuilding an instance now stops its background helpers too. ChatGPT's crash reporter and modifier monitor used to keep running after the app had gone, pointing at a bundle that no longer existed, and they built up quietly over time. Sparkle's own updater and the Computer Use helpers are deliberately left alone.
- `remove --purge-data` now also moves the instance's cache to the Trash, alongside its profile and `CODEX_HOME`. That cache was never cleaned up before, so it accumulated for every instance ever removed. The stock ChatGPT app's own cache is protected the same way its profile already was.
