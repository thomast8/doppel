# Doppel 2.0.0-beta-3

- Disabling Remote Access now revokes the phone key before it closes open sessions, so a phone that connects at that moment can't slip in and keep running.
- You can switch a disabled profile to a different ChatGPT account, and Enable works again after Disable without signing in a second time. Doppel still checks that the live account matches the one you confirm before turning access on.
- Replace Key and Update Runtime now appear while a profile is disabled, which is when they can run.
- The menu notices engine changes made from the `doppel` command line within a few minutes. Running a profile on official ChatGPT now lives under each instance's Fallback Engine submenu, since clones are the normal engine.
- Beta builds point at the beta update feed by default, so a beta install keeps receiving later betas.

This is a beta. Remote Access limits from beta-2 still apply: the Mac must stay awake and logged in, and macOS 14 execution, logout/login recovery and network-loss recovery still need broader testing.
