# Doppel 2.0.3

- Instances can now share a Creator Micro by Bluetooth channel. Run `doppel micro channel "ChatGPT Personal" 3` to keep an instance to channel 3, and switching apps becomes a press of the pad's channel button, with every app left running. Free channels can go to another app, such as a Claude Code plugin.
- An instance with a channel uses the pad even when it is not the assigned one. `doppel micro channel` lists the channels, and `any` in place of the number removes one.
- Rebuild each instance once from the Doppel menu to install the change, then pair each channel you use with this Mac.
