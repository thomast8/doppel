# Doppel 2.0.1

- Fixes ChatGPT updates that left Personal and Veridue stuck on the old build. ChatGPT 26.1016 changed how it reports its OAuth callback, and Doppel could not patch it.
- Doppel now tests a new ChatGPT build against its patcher before closing or replacing anything. If the build is not compatible yet, the update stops with a clear message and your current apps keep working.
- After updating Doppel, run the ChatGPT update again from the Doppel menu if you are still on 26.1013.
