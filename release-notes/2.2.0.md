# Doppel 2.2.0

- Each ChatGPT and Claude instance now has a Browser section with its own Chrome profile. The profile stays tied to the instance when you rename it, and your main Chrome is not touched. Claude One, for example, gets a Claude Code launch command that uses its own configuration folder.
- You confirm that the app and its browser are signed in to the same account before Doppel shows connection steps or pairs the ChatGPT extension. Existing standalone profiles are kept and can be linked to an instance once the profile is closed. Doppel never deletes browser data.
- The profile that runs on the official ChatGPT app is now called the official engine, and `doppel engine` replaces `doppel browser` (the old name still works). That profile is the only one that can use appshots and Computer history, because ChatGPT only accepts those from its own signed app. The in-app browser works in every instance.
