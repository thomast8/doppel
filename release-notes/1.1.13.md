# Doppel 1.1.13

- The menu now notices engine changes made from the `doppel` command line within a few minutes, instead of showing an instance on official ChatGPT until you click Refresh.
- Running a profile on official ChatGPT is now under each instance's Fallback Engine submenu. Clones are the normal engine, so the menu no longer leads with it. A profile actually on the fallback still shows that at the top, with Switch Back to Doppel Engine.
