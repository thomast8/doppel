# Doppel 2.0.4

- New **Use with Claude Code** in the Creator Micro menu, and `doppel micro claude <channel>` on the command line. Doppel installs the codex-micro Claude Code plugin, turns on the setting the Claude app's Code tab needs, and keeps the plugin to its own Bluetooth channel, so ChatGPT and Claude Code share the pad by channel.
- Doppel shows everything it will change and only goes ahead once you confirm.
- A ChatGPT instance and Claude Code can no longer be given the same channel, and `doppel micro channel` now lists Claude Code too.
