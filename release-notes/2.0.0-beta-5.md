# Doppel 2.0.0-beta-5

- Disabling Remote Access now revokes the phone key before it closes open sessions, so a phone that connects at that moment can't slip in and keep running.
- You can switch a disabled profile to a different ChatGPT account. Signing in no longer fails against the previous account, and Enable locks in the one you confirm.
- Replace Key and Update Runtime now appear while a profile is disabled, which is when they can run.

This is a beta. Remote Access limits from earlier betas still apply: the Mac must stay awake and logged in, and macOS 14 execution, logout/login recovery and network-loss recovery still need broader testing.
