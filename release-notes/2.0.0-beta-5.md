# Doppel 2.0.0-beta-5

- Fixes clone rebuilds on ChatGPT 26.1013. That build changed how it hands deep links to the app, so Doppel could not patch the OAuth callback routing and every instance failed to start with "Patching the instance OAuth callback routing failed".

Includes [PR #56](https://github.com/thomast8/doppel/pull/56).

This remains a beta. Remote Access requires the Mac to stay awake and logged in. Menu-click and physical-keypad reconnection QA remain incomplete, and macOS 14 execution, logout/login recovery, and network-loss recovery still need broader testing.
