# Doppel 2.0.5

- Doppel no longer keeps every ChatGPT update it has ever downloaded. After an update it keeps the newest download, the newest two rollback copies and only a prepared build that is still waiting to install. On one Mac these leftovers had grown to 31 GB.
- The rollback copy for the ChatGPT build you are running is never removed, so rolling back still works.
- QA builds and builds that fail or are interrupted no longer leave 1.7 GB app copies behind in their staging folders.
- `doppel prune` with no name now tidies the updates folder too and includes it in the size it reports. Run it once after updating to clear what earlier versions left behind.
