# Doppel 2.0.0-beta-4

- Failed actions now show short messages instead of command-output dumps. For example, a disk-full extraction error tells you to free space and retry. Full CLI diagnostics are saved locally with owner-only permissions.
- Assign Creator Micro to a managed instance from Doppel’s menu. Assignment changes automatically restart affected running instances; selecting the current owner leaves it alone. Save unfinished drafts before changing the assignment. Official ChatGPT also uses the keypad while it runs.
- Release Assignment can clear an old assignment after its instance was removed.

Includes [PR #55](https://github.com/thomast8/doppel/pull/55) and [PR #54](https://github.com/thomast8/doppel/pull/54).

This remains a beta. Remote Access requires the Mac to stay awake and logged in. Menu-click and physical-keypad reconnection QA remain incomplete, and macOS 14 execution, logout/login recovery, and network-loss recovery still need broader testing.
