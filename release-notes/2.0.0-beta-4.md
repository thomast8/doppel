# Doppel 2.0.0-beta-4

- After you disable Remote Access for a profile, Enable works again without signing in a second time. Doppel still checks that the live account matches the one you confirmed before it turns access back on.
- Beta builds now point at the beta update feed by default, so a beta install keeps receiving later betas.

This is a beta. Remote Access limits from earlier betas still apply: the Mac must stay awake and logged in, and macOS 14 execution, logout/login recovery and network-loss recovery still need broader testing.
