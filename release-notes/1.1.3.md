# Doppel 1.1.3

- Notices when ChatGPT has updated itself and left managed instances on an older version, instead of reporting everything as up to date.
- Offers to rebuild just the instances that are behind, from the ChatGPT app already installed: nothing is downloaded, ChatGPT itself keeps running, and instances that already match are left open.
- No longer offers to install a version that is already installed, which used to fail with "is not newer than the installed build".
