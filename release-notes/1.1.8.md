# Doppel 1.1.8

- Installing a ChatGPT update no longer stops when a profile is using the built-in browser. That profile runs through the untouched official app rather than through its own clone, and Doppel previously had no way to put such a window back, so it refused the whole update and asked you to quit the window yourself. It now closes that window along with everything else and reopens it on the same profile, with the same account data and the vendor's own updater still disabled. It still stops before touching anything when the official window belongs to a different profile, to a profile Doppel does not manage, or when more than one is open, and it names the window to quit.
- When ChatGPT asks you to confirm quitting, Doppel now brings that dialog to the front and gives you two minutes to answer it. ChatGPT refuses the quit request instantly and only then puts its "Quit ChatGPT?" dialog on screen, often behind another window, so Doppel used to give up after forty seconds and tell you to dismiss a keychain prompt that was never there. If it does still give up, it now tells you to click Quit in ChatGPT's own dialog.
