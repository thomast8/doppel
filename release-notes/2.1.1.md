# Doppel 2.1.1

- Doppel can update to ChatGPT 26.1027 and newer again. That build changed how the app is packaged, and Doppel refused to update with "this ChatGPT build is not compatible with Doppel yet". Your existing ChatGPT apps were never touched and kept working.
- Doppel is now less likely to break the next time ChatGPT repackages itself. A plain change in how the app writes its code no longer stops an update.
- Developers can run `just qa-vendor` to check the installed and any downloaded ChatGPT build against Doppel before applying an update.
