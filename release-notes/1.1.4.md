# Doppel 1.1.4

- Rebuilds instances again on ChatGPT 26.818 and later. The previous version could not patch the newest ChatGPT layout, so instances failed with "Patching the instance OAuth callback routing failed" and would not start.
- Recognises the reworked deep-link handling in current ChatGPT builds without pinning to one release, so a routine ChatGPT update no longer strands your instances.
