# Doppel 2.1.0

Create separate Claude desktop apps from New Instance → Claude, each with its own login, Code configuration, name and colour. Google sign-in returns to the right instance, and Claude's pale star stays visible on tinted icons.

After signing in and opening Code, use Import Existing Code History to bring over local conversations for the same account and workspace. Existing sessions and original files are kept. Missing transcripts and working folders are reported. Working copies are not moved, so check the original folder for uncommitted work if Claude creates a new worktree when resuming a conversation.
