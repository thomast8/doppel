# Doppel 2.0.0

- Set up iPhone Codex access from each profile's new Remote Access window. Keep Personal and Work as separate phone connections with independently signed-in accounts and managed runtimes.
- Choose your existing LAN or private network, including Meshnet. Doppel supplies the connection details and an iPhone-compatible PEM key without enabling macOS Remote Login.
- Check the live remote account, replace a phone key, update one remote runtime, or revoke a connection from the GUI. Remote Access remains off until you enable it.

Remote tasks use the Mac user's filesystem permissions. The Mac must remain awake and logged in. Desktop history, Browser, Computer Use and cloud synchronization are outside this release.
