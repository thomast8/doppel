# Doppel 2.0.0

- Set up iPhone Codex access from each profile's new Remote Access window. Keep Personal and Work as separate phone connections with independently signed-in accounts and managed runtimes.
- Choose your existing LAN or private network, including Meshnet. Doppel supplies the connection details and an iPhone-compatible PEM key without enabling macOS Remote Login.
- Confirm the live remote account and workspace before enabling access. Replace a phone key, update one remote runtime, or switch accounts while access is disabled. Disabling access revokes the phone key before closing open sessions; you can enable it again without signing in again.
- Choose Receive Beta Updates in the Doppel menu to switch update channels. Your selection persists after updating; switching off waits for a newer stable release.
- Cloned apps now launch on their pinned Dock icon, and automatic startup repair preserves the app directory. Rebuild each existing instance once after updating Doppel to install the updated launcher.

Remote tasks use the Mac user's filesystem permissions. The Mac must remain awake and logged in. Desktop history, Browser, Computer Use and cloud synchronization are outside this release.
