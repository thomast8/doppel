# Doppel 1.1.11

- macOS no longer shows "You can't open the application ….app.rollback because it may be damaged or incomplete". Doppel now hides the backup it keeps from each rebuild as a plain folder, so macOS no longer treats it as a broken app. Existing backups are converted the next time Doppel repairs them (`native-tools repair`).
- An error dialog left open after a failed rebuild no longer blocks Doppel. Before, every later launch or rebuild failed with "another Doppel engine operation is already in progress" until the dialog was closed. Each instance picks up the fix on its next rebuild.
- `native-tools status` now shows whether the in-app browser works inside each running instance. Current ChatGPT builds allow it in instances. If a future build blocks it again, the status says so, and you can give that profile the built-in browser instead.
- Installing ChatGPT updates no longer stalls on a suspended permission check, and instances build again from ChatGPT build 12404.
