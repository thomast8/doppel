# Doppel 1.1.6

- Brings an instance to the front when its ChatGPT profile is already open in another ChatGPT window, instead of bouncing in the Dock and opening nothing. This affected an instance that shares ChatGPT's own profile folder: the official app claims that profile as soon as it starts, so the instance could never take it and quit again a moment after the click. Clicking its icon now raises the window that actually has the profile.
